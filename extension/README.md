# TTLI Tracker

Локальное расширение Chrome/Edge для Time To Lock In. Оно отправляет приложению
только hostname активной вкладки и её заголовок. Полный URL не сохраняется и не
передаётся.

## Установка в Chrome

1. Запусти приложение TTLI.
2. Открой `chrome://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери папку `extension/`.

В Edge используй `edge://extensions`, включи **Режим разработчика** и нажми
**Загрузить распакованное расширение**.

## Связь с приложением

1. Скопируй токен расширения из онбординга или настроек TTLI.
2. Открой TTLI Tracker на панели расширений.
3. Вставь токен и нажми **Сохранить**.
4. Статус `TTLI подключён` означает, что локальное API приложения доступно.

TTLI должен быть запущен. Расширение обращается только к
`http://127.0.0.1:43110` и не делает внешних запросов.
