# PRD: TimeForge — Desktop Activity Tracker (v1)

> Рабочее имя — TimeForge (семейство Forge). Нейминг открыт, варианты в конце.
> Grill-me (2026-08-10) → PRD v1 → 3-раундовая дискуссия с Codex (gpt-5.6-sol) → v2. Консенсус зафиксирован в секции «Дискуссия».

## Problem

Человек проводит за компьютером 8-12 часов в день и не знает, куда реально уходит время. Ручное логирование умирает за неделю, готовые трекеры (RescueTime, ActivityWatch) — серые, негеймифицированные, с чужими категориями. Хочется автоматическую приватную штуку, которая сама знает, что Steam — это брейнрот, мотивирует делать дела и даёт красивый артефакт, который не стыдно кинуть кентам.

## Product Loop (главный цикл)

`автонаблюдение → классификация → зачёт дня → терминальная Печать → картинка кенту → локальный челлендж → установка без регистрации`

## Success Criteria (все бинарные, проверяемые за день)

- [ ] **First-run (60 сек)**: за первые 60 секунд после первого запуска юзер видит реально обнаруженное приложение, принимает useful-цель и waste-лимит, классифицирует один настоящий сегмент и видит его на живом дашборде. Установка расширения браузера НЕ блокирует завершение онбординга
- [ ] 10 минут в Steam + 10 минут кода → дашборд показывает два сегмента в правильных категориях
- [ ] Создание категории «Brainrot» + правило `steam.exe → Brainrot` за < 1 минуту, работает сразу (без рестарта)
- [ ] В Chrome: ютуб и гугл-док в разных вкладках — статистика их различает (через расширение)
- [ ] Public XP капает (1 XP/мин useful), ранг растёт по мемной шкале, хитмап недели заполняется
- [ ] Переклассификация сегмента (Brainrot → Work) пересчитывает XP, зачёт дня и графики задним числом
- [ ] В конце дня доступна «Печать дня» (терминальный лог-вердикт) и PNG-карточка для кента
- [ ] Челлендж: сгенерированный код `TF-184-43-60` импортируется на чистой машине, цели сохраняются локально
- [ ] После перезагрузки ПК трекер сам поднялся, данные целы (потеря максимум 5 сек)

## Scope

### In scope (v1)
- Вотчер активного окна (Windows, GetForegroundWindow, поллинг 5 сек). **TimeForge игнорирует собственные окна**
- Расширение Chrome/Edge (MV3): шлёт домен + тайтл вкладки в локальный HTTP-эндпоинт
- **Онбординг 60 сек** (см. «First-run» ниже): локальность → готовые категории → расширение (пропускаемое) → живой дашборд
- Кастомные категории: CRUD, цвет, иконка, kind (useful / neutral / waste). Дефолт при первом запуске: Work / Chill / Brainrot — как готовый старт, а не форма настройки
- Правила классификации: exe / процесс / подстрока тайтла / домен → категория, приоритет правил
- **Умные подсказки правил**: вечером «1.2 ч в Figma — это Work? Создать правило?» — одно нажатие
- Переклассификация задним числом (клик по сегменту → сменить категорию → пересчёт)
- Локальная БД SQLite; никаких внешних вызовов
- Дашборд: **живой** (текущее приложение, растущий сегмент таймлайна), сегодня (кольцо категорий + кликабельный таймлайн дня), хитмап недели/месяца, тренды 7/30, топ категорий
- **Зачтённый день**: день зачтён ⇔ `useful >= цель` И `waste <= лимит` И `observed >= 60 мин`. Цели настраиваются в онбординге. Достижение выдаётся после завершения дня; переклассификация пересчитывает задним числом; пропуск дня не отнимает заработанное
- **Печать дня (единый компонент)**: дневной вердикт в форме терминального агрегированного лога — три условия дня, useful/neutral/waste, Public XP, ранг, «сожжено ₽» (opt-in по часовой ставке). Используется: первое открытие после дня, история по дням, источник PNG
- **Public XP**: = полные минуты в useful. Единая неизменяемая формула. Переклассификация пересчитывает. Личные множители (`goal_multiplier`) — только для локальных целей, НЕ влияют на XP/ранг/карточки
- **8 мемных рангов без деградации** (по накопленному Public XP): Хомяк → Стажёр → Кодер → Фокусник → Тайм-ниндзя → Киберсамурай → Архитектор времени → Повелитель времени
- **Share v1 — ровно 3 PNG-артефакта** (никакой сетевой отправки, юзер сам кидает в мессенджер):
  1. `Печать дня` (вертикальный PNG: условия дня, статус «ДЕНЬ СИЛЫ»/«ДЕНЬ ЗОМБИ», ранг, бары категорий, burned ₽, «Tracked locally. No screenshots.», QR/ссылка на установку). Кнопка «Скинуть Печать дня», не «Export»
  2. `Неделя / Rank` (7 печатей, зачтено 5/7, useful/waste за неделю, XP, ранг, самый сильный день, «слито N рабочих дней», ₽ opt-in)
  3. `Челлендж` — «Побей мой день»: цель из результата отправителя, код `TF-<useful>-<waste>-<observed>` (только числа, без личности), QR на установку. Импорт кода на first-run → локальные цели → `CHALLENGE PASSED/FAILED` в конце дня
- Трей: живой счётчик useful-времени, ховер — раскладка дня, клик — перекинуть текущее окно в другую категорию; меню: открыть / пауза / выход; автозапуск через плагин
- **Кенты поюзают (требование юзера)**: установщик (NSIS .exe) + стабильная страница релиза с QR — кент ставит себе такой же локальный инстанс без регистрации. Сравнение и споры — через карточки и челлендж-коды между инстансами. Никакого сервера: каждый трекает своё локально

### OUT of scope (v1 — НЕ строить)
- Облако, синк, телефон, веб-версия, аккаунты, мультиюзер (кенты — через share-артефакты, v1.5+ для реальных дуэлей)
- macOS / Linux
- AI-инсайты «почему я так живу» (v1.2+)
- Блокировка сайтов/приложений, Pomodoro-таймер, напоминания
- Анализ содержимого окон (скриншоты, OCR)
- Многослайдовый сюжетный Wrapped (мемные номинации, анимация) — v1.1; в v1 только недельная карточка
- Соц-механики: лидерборды, недельные дуэли, совместные цели, инвайты

## First-run (60 секунд, пошагово)

- **0–5с**: запуск в трее, экран «Всё хранится локально», статус «Трекинг запущен», кнопка «Продолжить»
- **5–15с**: экран категорий с готовыми Work / Chill / Brainrot + кнопка «Оставить и начать» (изменение названий — опционально). Цели: useful-цель и waste-лимит (дефолты 120/60)
- **15–30с**: «Установить расширение Chrome/Edge» или «Пропустить». После установки — зелёный статус «Браузер подключён»
- **30–60с**: живой дашборд: текущее приложение, первый растущий сегмент, 0 XP, ранг «Хомяк», подсказка «Поработай минуту — увидишь первую статистику»
- Нулевой дашборд НЕ является первым экраном. Установка расширения — первая post-onboarding задача

## Constraints

- Windows 10/11 (Даня: Win10 19045), Chrome или Edge
- Tauri v2 (Rust backend + React/TS frontend), `tauri-plugin-autostart`, `tauri-plugin-sql`
- Rust-часть минимальна: вотчер (windows crate) + HTTP-listener (axum); логика в TS
- Расширение: Manifest V3, пишет ТОЛЬКО в localhost вотчер (не в БД напрямую)
- SQLite локально: `%APPDATA%/timeforge/`
- Ноль телеметрии, ноль внешних запросов. Приватность = фича. На карточках: «Tracked locally. No screenshots.»
- Производительность: вотчер < 1% CPU, память < 200 MB
- Public XP: единая формула, никаких множителей; `goal_multiplier` в схеме вместо `exp_multiplier`
- Шрифты/токены — строго по DESIGN.md (Rosé Pine Dawn)

## Edge Cases & Risks

- **Idle** (нет ввода > 5 мин, GetLastInputInfo): сегмент `away`, в категории и observed не идёт. Порог настраивается
- **Лок-скрин / UAC / LockApp.exe**: фильтруется как `away`
- **Игры fullscreen**: GetForegroundWindow в большинстве случаев работает; погрешность принимаем
- **Браузер без расширения**: fallback на тайтл окна (правила по подстроке). Работает, но грубее
- **Расширение перезапустилось**: retry-коннект к localhost каждые 30 сек
- **Выключение ПК посреди сегмента**: сегмент флашится при каждой смене окна + раз в 60 сек; теряется максимум 5-60 сек
- **Переклассификация**: каскадный пересчёт XP / зачёта дня / daily_stats для всех затронутых дней — одним запросом агрегации
- **Нет правил для процесса**: `Uncategorized` — виден на дашборде, в observed/XP не идёт (observed = useful+neutral+waste только)
- **DST / смена часового пояса**: агрегация по локальной дате, погрешность допустима
- **Шумный день**: Печать дня — агрегированный лог, НЕ перечень каждого переключения окна (иначе сотни строк)
- **Денежная строка**: только при заданной часовой ставке (opt-in)
- **QR/ссылка на установку**: нужен стабильный URL релиза (TBD — GitHub Releases или свой хостинг)

## Architecture (rough)

```
timeforge/
├─ src-tauri/            # Rust
│  ├─ src/watcher.rs     # поллинг GetForegroundWindow 5с + GetLastInputInfo (idle)
│  ├─ src/http.rs        # axum: POST /event {app, title, domain} от расширения
│  └─ main.rs            # трей (счётчик useful), автозапуск, команды
├─ src/                  # React + TS
│  ├─ pages/Onboarding.tsx   # 60-сек флоу: локально → категории/цели → расширение → live
│  ├─ pages/Dashboard.tsx    # живой дашборд: текущее окно, кольцо, таймлайн
│  ├─ pages/Heatmap.tsx      # хитмап недели/месяца
│  ├─ pages/Trends.tsx       # тренды 7/30, топ категорий
│  ├─ pages/Categories.tsx   # CRUD категорий и правил (+ умные подсказки)
│  ├─ pages/History.tsx      # переклассификация, зачтённые дни, Печать дня
│  └─ lib/share.ts           # рендер 3 PNG-карточек + код челленджа
├─ extension/            # MV3: chrome.tabs → POST localhost
└─ docs/prds/
```

- **SQLite (source of truth — миграции):**
  - `categories(id, name, color, icon, kind[useful|neutral|waste], goal_multiplier, created_at)`
  - `rules(id, match_type[exe|title|domain], pattern, category_id, priority)`
  - `segments(id, ts_start, ts_end, app, window_title, domain, category_id, status[active|idle|away])`
  - `daily_stats(date, category_id, duration_ms, xp)` — агрегат хитмапа/зачёта
  - `settings(key, value)` — цели (useful_goal, waste_limit), hourly_rate (nullable), observed_min
- Ранг = пороги по накопленному Public XP (8 мемных, без деградации). Зачёт дня — по правилу трёх условий
- Челлендж: код `TF-<useful>-<waste>-<observed>` — чистая сериализация трёх чисел, без сервера

## Дискуссия с Codex (gpt-5.6-sol, 3 раунда) — зафиксированный консенсус

1. **Public XP отдельно от личных целей**: единая формула 1 XP/мин useful; множители только для локальных целей (`goal_multiplier`); стрик-бонус ×1.5 удалён
2. **Стрик «чистого времени» заменён на «Зачтённый день»** (три условия) — абсолютный стрик мотивировал бы переименовывать категории
3. **Печать дня = терминальный лог + вердикт + деньги** (opt-in) — один компонент вместо трёх функций
4. **First-run зафиксирован как проверяемый сценарий** (60 сек, см. Success Criteria)
5. **Share v1 = 3 артефакта** (Печать дня / Неделя / Челлендж с кодом) — вирусность через мессенджеры без аккаунтов; Wrapped multi-slide — в бэклог
6. **Ранги мемные, без деградации** — «Киберсамурай» продаёт лучше «GOLD III»; деградация только через дневные вердикты

## Конфетки (креативная сессия, 2 субагента + Codex)

- **Умные подсказки правил** — приложение само умнеет, убивает боль настройки (v1)
- **Деньги впустую** — waste × часовая ставка = «сожжено ₽», строчка на Печати дня (v1, opt-in)
- **Живой трей** — счётчик useful в иконке, переклассификация с трея (v1)
- **Челлендж «Побей мой день»** — локальный код цели, асинхронный спор без сервера (v1)
- **Недельная rank-карточка** — 7 печатей, зачтено 5/7, «слито N рабочих дней» (v1)

### Бэклог v1.1+ (не строим в v1)
- Многослайдовый сюжетный Wrapped (мемные номинации, анимация)
- Босс недели (HP = минуты waste прошлой недели, урон = useful-минуты)
- Комбо-мультипликатор (×1 → ×1.5 за 25-мин блоки фокуса подряд)
- Страховка стрика (щит за фокус-часы)
- Золотой час (случайный час дня ×2, вспышка в трее)
- Лутбокс фокуса (титулы, скины темы за каждые 3ч useful)
- Скрытые ачивки-мемы («Ночной страж» — 5ч YouTube после 2 ночи)
- Маскот-компаньон в трее (ест фокус-часы)
- Проверка часовым (тост «Ты в Brainrot 47 минут. Продолжаем?» + EXP за осознанность)
- Инсайты: Зона силы, детект потока, фрагментация дня, хитмап дёрганий
- Квесты из данных, Стена позора + Зал славы, Пятница-зарплата, Prestige (+5% навсегда)
- Мультиюзер-дуэли для кентов (когда сам поюзает)
