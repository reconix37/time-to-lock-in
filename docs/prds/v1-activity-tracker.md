# PRD: TimeForge — Desktop Activity Tracker (v1)

> Рабочее имя — TimeForge (семейство Forge). Нейминг открыт, варианты в конце.
> Синтезировано из grill-me сессии (2026-08-10). Достроено креативными субагентами.

## Problem

Человек проводит за компьютером 8-12 часов в день и не знает, куда реально уходит время. Ручное логирование умирает за неделю, а готовые трекеры (RescueTime, ActivityWatch) — серые, негеймифицированные и с чужими категориями. Хочется автоматическую приватную штуку, которая сама знает, что Steam — это брейнрот, мотивирует EXP-шкой делать дела и показывает «вот сколько ты слил».

## Success Criteria (все бинарные, проверяемые за день)

- [ ] После установки: иконка в трее, автозапуск в Windows (re-login), клик по трею открывает дашборд за < 1 сек
- [ ] 10 минут в Steam + 10 минут кода → дашборд показывает два сегмента в правильных категориях
- [ ] Создание категории «Brainrot» + правило `steam.exe → Brainrot` за < 1 минуту, работает сразу (без рестарта)
- [ ] В Chrome: ютуб и гугл-док в разных вкладках — статистика их различает (через расширение)
- [ ] EXP капает за время в полезных категориях, уровень растёт, хитмап недели заполняется
- [ ] Переклассификация сегмента (Brainrot → Work) пересчитывает EXP и графики задним числом
- [ ] Фича «сколько бы я успел» показывает цифру за неделю («слито N рабочих дней»)
- [ ] После перезагрузки ПК трекер сам поднялся, данные целы (потеря максимум 5 сек)

## Scope

### In scope (v1)
- Вотчер активного окна (Windows, GetForegroundWindow, поллинг 5 сек)
- Расширение Chrome/Edge (MV3): шлёт домен + тайтл вкладки в локальный HTTP-эндпоинт
- Кастомные категории: CRUD, цвет, иконка, kind (useful / neutral / waste), множитель EXP
- Правила классификации: exe / процесс / подстрока тайтла / домен → категория, приоритет правил
- Переклассификация задним числом (клик по сегменту → сменить категорию → пересчёт)
- Локальная БД SQLite; никаких внешних вызовов
- Дашборд: сегодня (кольцо по категориям + таймлайн дня), хитмап недели/месяца (GitHub-style), тренды 7/30 дней, топ категорий
- EXP: 1 XP/мин в useful-категориях (множитель настраивается), уровни (кривая), стрик-бонус
- «Сколько бы я успел»: waste-время за период ÷ средняя дневная полезность = «слито N рабочих дней»
- **Share для кентов (требование юзера)**: карточка дня/недели в PNG (хитмап + статы + звание) — «скинуть кентам» одним файлом; Wrapped-недели в этой же механике
- Трей: открыть / пауза / выход; автозапуск через плагин

### OUT of scope (v1 — НЕ строить)
- Облако, синк, телефон, веб-версия
- macOS / Linux
- Мультиюзер, аккаунты, «кенты» (v1.5+, когда сам поюзает)
- AI-инсайты и аналитика «почему я так живу» (v1.2+)
- Блокировка сайтов/приложений, Pomodoro-таймер, напоминания
- Анализ содержимого окон (скриншоты, OCR) — только названия

## Constraints

- Windows 10/11 (Даня: Win10 19045), Chrome или Edge
- Tauri v2 (Rust backend + React/TS frontend) — лёгкий десктоп, нативный трей, `tauri-plugin-autostart`, `tauri-plugin-sql`
- Rust-часть минимальна: вотчер (windows crate) + HTTP-listener (axum); вся логика в TS
- Расширение: Manifest V3, пишет ТОЛЬКО в localhost вотчер (не в БД напрямую)
- SQLite локально, путь: `%APPDATA%/timeforge/`
- Ноль телеметрии, ноль внешних запросов. Приватность = фича
- Производительность: вотчер < 1% CPU, память < 200 MB
- Категории НЕ захардкожены: дефолтные (Work / Chill / Brainrot) создаются при первом запуске как примеры, юзер волен их удалить

## Edge Cases & Risks

- **Idle** (нет ввода > 5 мин, GetLastInputInfo): сегмент помечается away, в категории и EXP не идёт. Порог настраивается
- **Лок-скрин / UAC / LockApp.exe**: фильтруется как away
- **Игры fullscreen**: GetForegroundWindow в большинстве случаев работает; погрешность принимаем, фикс при необходимости
- **Браузер без расширения**: fallback на тайтл окна (правила по подстроке тайтла, e.g. «YouTube»). Работает, но грубее
- **Расширение перезапустилось**: retry-коннект к localhost каждые 30 сек
- **Выключение ПК посреди сегмента**: сегмент флашится при каждой смене окна + раз в 60 сек; теряется максимум 5-60 сек
- **Переклассификация**: каскадный пересчёт EXP/daily_stats для всех затронутых дней — делается одним запросом агрегации
- **DST / смена часового пояса**: агрегация по локальной дате, погрешность допустима
- **Нет правил для процесса**: попадает в «Uncategorized» (виден на дашборде, EXP не даёт) — юзер решает, что с ним делать

## Architecture (rough)

```
timeforge/
├─ src-tauri/            # Rust
│  ├─ src/watcher.rs     # поллинг GetForegroundWindow каждые 5с + GetLastInputInfo (idle)
│  ├─ src/http.rs        # axum: POST /event {app, title, domain} от расширения
│  └─ main.rs            # трей, автозапуск, команды для фронта
├─ src/                  # React + TS
│  ├─ pages/Dashboard.tsx    # сегодня: кольцо + таймлайн
│  ├─ pages/Heatmap.tsx      # хитмап недели/месяца
│  ├─ pages/Trends.tsx       # тренды 7/30, топ категорий
│  ├─ pages/Categories.tsx   # CRUD категорий и правил
│  ├─ pages/History.tsx      # переклассификация задним числом
│  └─ lib/db.ts              # вызовы команд Tauri
├─ extension/            # MV3: background.js слушает chrome.tabs, POST на localhost
└─ docs/prds/
```

- **SQLite-схема (source of truth — миграция):**
  - `categories(id, name, color, icon, kind, exp_multiplier, created_at)`
  - `rules(id, match_type[exe|title|domain], pattern, category_id, priority)`
  - `segments(id, ts_start, ts_end, app, window_title, domain, category_id, status[active|idle|away])`
  - `daily_stats(date, category_id, duration_ms, exp)` — агрегат для хитмапа/EXP
- EXP = сумма(duration в useful) × множитель категории; стрик-бонус ×1.5 при стрике ≥ 7 дней. Уровень = floor(sqrt(exp/100)) (кривую подгоним)
- «Сколько бы я успел» = Σ(waste за период) ÷ средняя дневная Σ(useful за 30 дней) → «слито N рабочих дней»

## Конфетки (креативная сессия, 2 субагента)

Отобрано из 30 идей двух независимых сессий (геймдизайн + продукт/UX). Всё работает на уже собранных данных — без новых интеграций.

### Входят в v1 (максимум вау на минимум кода)
- **Умные подсказки правил** — вечером: «1.2 ч в Figma — это Work? Создать правило?» — одно нажатие. Убивает боль настройки, приложение само умнеет с каждым днём
- **Дневной вердикт (Печать дня)** — вечером выносится вердикт («День силы» / «Рабочий день» / «День зомби») + штамп в календарь; цепочка штампов = стрик. Ритуал закрытия дня
- **Деньги впустую** — брейнрот-часы × твоя часовая ставка = «сожжено ₽» (вишенка «сколько бы я успел» получает вторую форму). Настройка ставки в категориях
- **Живой трей** — счётчик «Work 4ч12м» в иконке, ховер — раскладка дня, клик — перекинуть текущее окно в другую категорию на лету
- **Терминальный дайджест** — утренний лог вчерашнего дня: `[09:14] figma — Work 45m` в вайбе продукта (Rosé Pine Dawn, Space Grotesk Mono)
- **Стрик чистого времени** — дни подряд без брейнрота в рабочее время (выходные не считаются), сбрасывается пропуском

### Бэклог v1.1+ (помечено, не строим в v1)
- Босс недели (HP = минуты брейнрота прошлой недели, урон = фокус-минуты, лут к воскресенью)
- Комбо-мультипликатор (×1 → ×1.5 за 25-мин блоки фокуса подряд, брейнрот сбрасывает)
- Страховка стрика (щит за фокус-часы, 1 раз/нед)
- Золотой час (случайный час дня ×2 EXP, вспышка в трее)
- Лутбокс фокуса (титулы, скины темы, мемные артефакты за каждые 3ч фокуса)
- Скрытые ачивки-мемы («Ночной страж» — 5ч YouTube после 2 ночи)
- Маскот-компаньон в трее (ест фокус-часы, грустит от брейнрота)
- Ранг с деградацией (Хомяк → Кодер → Киберсамурай, откат после 3 брейнрот-дней)
- Проверка часовым (тост «Ты в Brainrot 47 минут. Продолжаем?» + EXP за осознанность)
- Wrapped недели + share-карточка PNG (Spotify Wrapped-style, титулы, «самый верный спутник — Chrome»)
- Инсайты: Зона силы (час, когда ворк-сессии длиннее всего), детект потока (25+ мин без переключений), фрагментация дня (число переключений окон), хитмап дёрганий
- Квесты из данных (генерируются из твоих же правил, ежедневно новые)
- Стена позора + Зал славы, Пятница-зарплата, Prestige (Новая игра+ с вечным +5% EXP)

## Нейминг (открытый вопрос)

- **TimeForge** — семейство Forge (HabitForge → TimeForge), консистентно
- **Pulse** / **Momentum** / **Chrono** — коротко, вайб статистики
- **FocusForge** — акцент на продуктивность
- Решает Даня. Репо/папки переименовываются легко до первого коммита
