## Решения (проектирование: 2 субагента + синтез; Codex в лимите до 20.08 — реализация руками)
1. **П.1** «Поверх окон»: ключи mini.pin/unpin меняем значениями (не именами); иконка = два перекрытых окна; active = переднее залито.
2. **П.2** «В самый угол»: чекбокс mini_corner_tuck внизу corner-попапа (disabled без corner и при click-through). Окно уезжает за край рабочей области, виден пятачок 24×24; hover на окне = выезд, mouseleave 800мс = обратно (команда tuck_mini_position без записи в БД). restore_window_state/ save_mini_geometry учитывают tuck (позиция — производная, не сохраняем).
3. **П.3** click-through: тумблер в строке с opacity (виджет + настройки дашборда), set_ignore_cursor_events (WS_EX_TRANSPARENT+LAYERED сам), **запасной путь — CheckMenuItem «Клики сквозь» в трей-меню** (3 локали, синхронизация checked), бейдж «сквозь» в шапке, авто-закрытие попапа 3с.
4. **П.4** % из hero → в футер (mini-productive отдельной строкой).
5. **П.5** порог expanded → 390×280 (ровно половина растяжения); «Компактно» = точный resize (force) + set_resizable(false) + подпись «Компактно · окно фиксируется»; применяется и при старте.
6. **П.6** бары (mini-metrics) удалены из виджета, вместо них одна строка вердикта дня (getMiniVerdict — мёртвый код переиспользован); настройку «категории vs бары» не делаем (YAGNI — юзер сам в ступоре, одна строка вместо 88px).

## Критичный баг из поля (скрин Едуарда после v0.2.16)
«Anywhere»-правило не сохранялось: CHECK constraint схемы rules (001_init.sql:22) принимал только exe/title/domain — регрессия v0.2.15 (бэкенд-логика патчилась, схема нет).
**Фикс**: миграция 007_rule_match_any.sql — пересоздание rules с 'any' в CHECK (данные, idx_rules_lookup, уникальный индекс, match_mode/case_insensitive сохранены) + 001_init.sql обновлён для свежих БД + db.rs применяет 007 при previous_version < 7.
**Проверено функционально (python sqlite3)**: старый CHECK → IntegrityError (баг); после 007 → 'any' вставляется, user_version=7, уникальный индекс блокирует дубли, fresh-001 принимает 'any'.

## Проектные решения (субагент 1, UX — п.1-3; Codex недоступен до 20.08)

### П.1 «Поверх окон»
- Значения i18n `mini.pin`/`mini.unpin` меняем (ключи не трогаем): ru «Поверх окон» / «Снять „поверх окон“»; ua «Поверх вікон» / «Зняти „поверх вікон“»; en «Always on top» / «Remove always on top».
- Иконка: канцелярская кнопка → два перекрывающихся окна (переднее залито акцентным при активном). Читается как z-order. Различие со скрепкой (corner) жёсткое.
- grep-аудит: «Pin/Unpin» не должно остаться в тултипах/aria.

### П.2 «В самый угол» (tuck)
- Чекбокс ВНИЗУ corner-popover (юзер просил «снизу добавить галочку»): ru «В самый угол», title-хинт «Виджет спрячется за край экрана; наведи на угол — появится»; ua «У самий кут»; en «Tuck into the corner». Без corner-lock — disabled + хинт «Сначала закрепи в углу».
- Setting `mini_corner_tuck` (0/1, дефолт 0).
- Геометрия: видимый пятачок 24×24px в углу work_area; остальное за краем (ОС клипает). Формулы в move_mini_to_corner: bl: x=WA.left−(W−24), y=WA.bottom−24; br: x=WA.right−24; tl/tr аналогично. Отступ от таскбара = работаем от work_area.
- Hover-reveal: mouseenter → обычная corner-позиция (отступ 4px); mouseleave → таймер 800мс → tuck. Snap без анимации. Если открыт popover — не прятать. При ресайзе (onResized) пересчитать tuck.
- Снятие corner: сначала un-tuck (на экран целиком), потом set_resizable(true). Смена угла → пересчёт tuck.
- save_mini_geometry при corner-lock ПОДАВИТЬ (позиция производная). При tuck `mini_window_pos` не сохранять.
- Взаимоисключение с click-through: включение click-through при corner+tuck → un-tuck; чекбокс tuck disabled + хинт «Сначала выключи „клики сквозь“».
- restore_window_state: move_mini_to_corner учитывает tuck-флаг (иначе при рестарте «выпрыгнет»).

### П.3 Click-through
- Тумблер в ОДНОЙ строке с opacity-слайдером: `[Прозрачность 100% ———] [Клики сквозь]`. Зеркало в App Settings → секция мини.
- i18n: ru «Клики сквозь», ua «Кліки наскрізь», en «Click-through». Хинт: «Окно не ловит клики — они проходят приложениям под ним. Выключить: иконка TTLI в трее → „Клики сквозь“».
- Setting `mini_click_through` (0/1); применять при restore/show (как apply_mini_opacity).
- Техника: `set_ignore_cursor_events(bool)`; для Windows WS_EX_TRANSPARENT работает ТОЛЬКО с WS_EX_LAYERED — при включении гарантированно выставлять LAYERED (на 100% opacity он может быть не выставлен) + TRANSPARENT; при выключении — снять TRANSPARENT.
- Запасной путь: CheckMenuItem «Клики сквозь» в трей-меню (между Pause и Exit), 3 локали, двусторонняя синхронизация (виджет → set_checked; трей → окно+БД; виджет перечитает на 5-сек рефреше).
- Авто-закрытие попапа через ~3 сек после включения (клики по попапу не работают). Бейдж-пилюля в шапке «сквозь» (паттерн nowHiddenBadge).
- Hotkey — отклонить (зависимость + скрытая механика). «Клики сквозь» + «Поверх окон» — разрешено (киллер-фича: оверлей без перехвата кликов).
