# v0.2.9 — Референс: категории со скорингом (от юзера, 12.08.2026)

Три скрина от Дани — целевой UX раунда категорий. Это вижн-референс, не PRD;
конкретные решения (как score сочетается с kind, схема БД) — в дизайн-дебате.

## 1. Редактор категории (скрин «Edit category»)

- Заголовок «Edit category», X-закрытие
- **Name**: текст («Video»)
- **Parent**: dropdown («Work») — иерархия категорий
- **Rule**:
  - Type: dropdown «Regular Expression» (и другие типы)
  - Pattern: строка regex (`\b3d\b|blender|tutorial|course|texturing|rigging|anin`)
  - Case insensitive: toggle (on)
  - Предупреждение «Pattern too broad» (оранжевое) — валидация паттерна
- **Color**: Inherit parent color (toggle)
- **Productivity score**: Inherit parent score (toggle, off) + Score: число («5.5»)

## 2. Список категорий + правила (скрин слева)

- Иерархия: раскрывающиеся группы (Work (3), Waste of Time (4)) → подкатегории (Video, 3D, Ai Coach / Games, Socials (2))
- У категории: цветной кружок (Work=фиолет, Waste=красный), score зелёным (+) / красным (-): Work +10, Video +5.5, 3D +10, Ai Coach +3.5, Waste of Time -, Games -10, Socials -6
- Правила: родитель — «No rule»; подкатегория — «Rule (regex):» + мультилайн паттерн (magenta):
  - Video: `\b3d\b|blender|tutorial|course|eling|sculpting|shading|render|nodes|grease pencil|compositi`
  - 3D: `blender|capcut|pu`
  - Ai Coach: `google ai studio|…`
  - Games: `apex legends|game`
  - Socials: `tiktok|reddit|facebook|twitter|mbox|slack|riot|element|matter`

## 3. Дашборд скоринга (скрин справа)

Три колонки:
- **Top Categories**: список с полным путём «Waste of Time > Socials > telegram», время (1h 58m 54s), цвет категории (красный/синий/фиолет/серый), кнопка «Show more»
- **Score**:
  - «Your total score today is:» **-13.7** (крупно, красный/зелёный по знаку), «(9.3% productive)»
  - «Top productive:» — название + +значение (Anime [ENG] +1.0, Video +0.6 (Work), 3D +0.4 (Work))
  - «Top distracting:» — название + -значение (telegram -7.9 (Waste of Time > Socials), Videos and anime (ru) -7.5, Socials -0.3)
- **Timeline (barchart)**: стековые бары по часам (3..24), сегменты цветами категорий, высота = объём

## Ключевые решения (консенсус дебата с Codex, 12.08)

1. ✅ score **дополняет** kind (решение Дани). kind — цели/лимиты/зачёт, score — скоринг-дашборд.
2. ✅ Глубина дерева: **3 уровня** (root + 2). Наследуются цвет и score (флаги inherit_color/inherit_score), правила и kind НЕ наследуются. Reclassify через единый RuleSet (rules.rs).
3. ✅ Regex: крейт `regex = "1"` (без бэктрекинга, таймаут НЕ нужен), кэш скомпилированных паттернов, match_mode='legacy'|'regex' (отдельно от поля-мишени — НЕ match_type), case_insensitive per-rule.
4. ✅ «Pattern too broad»: блокер — не компилируется / is_match("")==true; warning — универсальная форма (.*, .+, ^.*$) ИЛИ ≥25% уникальных значений поля за 30 дней (≥20 значений). Preview «совпадёт с N из M, Xч Yм». Не блокирует сохранение.
5. ✅ Total score: аддитивные **score-hours**: category_points = effective_score × duration/3600000, total = Σ. Округление только на выводе. productive% = 100 × время в score>0 / observed (score 0 и Uncategorized в denominator). Top productive/distracting по category_points, Top Categories по длительности. Без rollup в родителей.
6. ✅ Score НЕ участвует в зачёте дня/XP/ранге (жёсткая граница — две системы истинности).
7. ✅ Миграция 005_categories_scoring.sql: parent_id, score REAL ±10 (default 0), inherit_color/inherit_score; match_mode, case_insensitive; существующие kind → +10/0/-10/0 (score независим от kind после миграции). Новый root: prefill по kind; child: наследует по умолчанию.
8. ✅ Выкинуть (YAGNI): новый hourly barchart, drag-drop дерева, неограниченная вложенность, наследование rules/kind, parent-rollups, score history, дефолт-настройки score, кастомный regex-движок, один Rule в редакторе, авто-массовый replay (существующий остаётся).
