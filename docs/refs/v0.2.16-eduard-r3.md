## Дискуссия с Codex (gpt-5.6-sol, 2 раунда) — зафиксированный консенсус

1. **Score — наш баг, не WebView**: `Number(event.target.value)` на каждом onChange превращает промежуточное «-» в NaN и контролируемый input перерисовывается. Фикс: `type=text` + отдельный строковый draft `scoreInput`; парсинг `-3.5/+3.5/3,5`; строгий диапазон [-10;10] с inline-ошибкой (без clamp); максимум 1 десятичный знак; blur нормализует `03.5→3.5`, `-0→0`, `3,5→3.5`; ArrowUp/Down = шаг 0.1; draft не затирает собственный score при inherit (при снятии inherit — показывать сохранённое, не effective). Без кнопок −/+.
2. **Форма правила — перестройка, не высота**: вертикальный стек (источник/оператор сверху, паттерн — растущий textarea на всю ширину, категория снизу). Переносы строк в паттерне → пробел (единая нормализация в preview/duplicate/save и в backend); литеральный `\n` (два символа) сохраняется; подсказка: «Переносы строк сохраняются как пробелы; для перевода строки в regex используйте \n».
3. **Палитра 12 цветов одной палитрой** (без отдельной «яркой»): тон Rosé Pine сохраняется, насыщенность — вариантными оттенками Moon; aria-pressed + локализованные человеческие имена; кастомный HEX остаётся.
4. **Иконки — полноценный end-to-end слайс v0.2.16**: локальный реестр 18 Lucide-paths (не lucide-react, не свои SVG); create/update прокидывают icon; backend allowlist (18 + «»), fallback `tag` при чтении; «Без иконки» разрешён; наследования нет; дефолтные `briefcase/coffee/skull` (уже в БД: db.rs:254-257) в allowlist; отображение: дерево категорий, picker формы, dashboard Top categories, ScorePanel, mini Top categories; не включать: таймлайн/сегменты/нативные select/правила/Печать дня. Единый модуль `CategoryMark` (точка + иконка; мини — иконка вместо точки, fallback — точка). Frontend-реестр == backend-allowlist (авто-тест).
5. **Пресеты категорий — отклонены** (YAGNI, дубли со стартовыми Work/Chill/Brainrot).
