## Главный вердикт
UI показывает внутреннюю модель (legacy/regex, числовой priority, 2 pin-механизма, сырой токен) вместо пользовательских действий. v0.2.12 меняет информационную архитектуру в 3 местах: Settings = единый центр настройки (секция Categories & rules), Mini = двухуровневый (compact контроль + expanded с Total score/Top categories), Dashboard = без дублей tooltip'ов + display-сессии.
