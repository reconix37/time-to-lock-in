## 2. Мини-виджет — minmax-строки (принято с поправками)
- compact (base): `24px minmax(56px,auto) minmax(20px,auto) minmax(68px,auto) minmax(20px,auto) minmax(0,1fr)`
- detailed (≥420×300): `24px minmax(64px,auto) minmax(20px,auto) minmax(64px,auto) minmax(20px,auto) minmax(37px,1fr) 36px`

- Поправка 1 — отступы: 12px compact / 16px detailed (не 14); вертикальный воздух — gaps 4/8, не padding.
- Поправка 2 — controls: settings 28×24 (ритм с нижними icon-кнопками); скрепка — ПО ЗАПРОСУ ЮЗЕРА «впритык»: MINI_CORNER_MARGIN 12 → 4 (Codex предлагал оставить 12 — отклонено: Даня явно просил «полностью с краю»; 4px = воздух для тени/рамки, визуально впритык).

- Кастомные select-стрелки: appearance:none + padding-right + SVG-chevron, цвет через CSS mask/background-color: var(--muted) (не зашивать в data URI); focus — iris.
