## Правила продукта
- **Сегменты**: одно состояние app+title+domain = сегмент, checkpoint 5с, flush на смене окна/pause/exit, висящие active → crashed при старте.
- **score ДОПОЛНЯЕТ kind** (v0.2.9): kind рулит целями/лимитами/зачётом дня, score (+10…−10) — только скоринг-дашборд. Score НЕ участвует в зачёте/XP/ранге. Две системы истинности, жёсткая граница.
- **Формат времени**: часы+минуты, секунды НИКОГДА. Единый форматтер `formatDuration` (App.tsx, ключи `duration.hoursHours`/`duration.minutes`, 3 локали) — не плодить новый.
- **i18n**: 3 локали (ru/ua/en), лёгкий словарь `src/i18n.ts` (`t(key, vars)`), БЕЗ react-i18next. **Ранги НЕ переводить** («Хомяк»→«Повелитель времени» — русские всегда), вердикты дня переводятся.
- **Приватность**: url НЕ хранится, только domain+title. Всё локально: никаких облаков/телеметрии/внешних вызовов (кроме localhost расширения).
- **Код на английском, комментарии — русские. TypeScript строгий (никакого `any`).** Токены/цвета/шрифты — только из `src/styles/tokens.css` (из DESIGN.md).
- **Никаких новых зависимостей без причины (Ponytail Ladder):** удали мёртвое → stdlib → известная библиотека → упрости → только потом новый код.
- **UI-канон**: нативные скроллбары = брак (кастомные, образец `.settings-scroll`); настройка, скрывающая данные (NOW-privacy), обязана показывать бейдж «Скрыто»; массовые/необратимые действия — дефолт ТОЛЬКО безопасный («только этот отрезок», ретро — явный opt-in с числом сегментов); каждая фича — явная кнопка в UI (скрытые механики = баг).

## Мини-окно (виджет)
- Размеры 300×228…480×340; expanded ≥420×300 — чистый CSS (`@media`). Движение ТОЛЬКО через `start_dragging`; замок 🔒 = drag-strip off + `set_resizable(false)` + `user-select:none`. Скрепка = corner-lock (4 угла, позиция от угла рабочей области, НЕ абсолютные координаты); НЕ смешивать с `mini_pinned` (● = always-on-top).
- **Все контентные строки grid = `minmax(min, auto)`** — строка растёт под контент, текст никогда не режется (канон v0.2.11). При правке размеров считать математику: ВСЕ строки × normal И large ×1.15 × ВСЕ брейкпоинты (<420, ≥420).
- Геометрия: `save_mini_geometry` на CloseRequested/Focused(false)/onResized И onMoved (иначе перетащил → вырубил комп = позиция потеряна).

## Проверка
- Фронт: `npm run build` (tsc + vite) — без ошибок.
- Rust: `cargo fmt` запускать ИЗ `src-tauri/` (`--manifest-path src-tauri/Cargo.toml`). `cargo test` принимает ОДИН фильтр (два — ошибка). Реальный прогон Rust-тестов — только CI.
- **Rust tail-expression = E0597**: не возвращай результат прямо из `query_map(...).collect()` — сначала `let records = ...?; drop(statement); Ok(records)`.
- Новый проп/параметр: проверить, что он прокинут из App.tsx (grep имени в JSX родителя) — класс багов «prop created, never wired».
- SQL: сверять каждый `?N` с параметрами `query_map` — регресс v0.1.9 уходил в релизы.
- Не верить «pre-existing failure» — проверять через `git show <прошлый тег>:<файл>`.
