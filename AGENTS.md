# AGENTS.md — Time To Lock In

## Канон (единственные нормативные источники)
- `docs/prds/v1-activity-tracker.md` — PRD v2 (готов к разработке). Читай перед любой задачей.
- `DESIGN.md` — дизайн-система (токены, компоненты, графики, антипаттерны).
- `src-tauri/migrations/` — схема БД (source of truth).
- Prior art (WakaTime и пр.) — НЕ норматив, поведение не заимствуется.

## Правила
- Vertical slices: каждый PR — рабочий путь данных целиком, не «слой».
- Сегменты: канон в PRD (одно состояние app+title+domain = сегмент, checkpoint 5с, flush на смене окна/pause/exit, висящие active → crashed при старте).
- Всё локально: никаких облаков, телеметрии, внешних вызовов (кроме localhost расширения).
- Приватность: url НЕ хранится, только domain+title.
- Код на английском, комментарии — русские. TypeScript строгий (никакого `any`).
- Токены/цвета/шрифты — только из `src/styles/tokens.css` (из DESIGN.md).
- Никаких новых зависимостей без причины (Ponytail Ladder).

## Проверка
- Фронт: `npm run build` (tsc + vite) — должно проходить без ошибок.
- Rust локально не собирается (Linux без webkit2gtk): проверка — на CI (GitHub Actions, windows-latest). Пиши код, который компилируется для cfg(windows); для не-windows давай заглушки.
- `npm run tauri dev` работает только на Windows у юзера.
